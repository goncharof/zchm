# Заклятье Чёрного мага — в браузере

Браузерная версия первой постсоветской настольной ролевой игры (ЗАО «Камелот», 1997).
Движок ведёт механику, Книга Жизни читается как книга-игра. Без сервера: статическая сборка,
сохранения в браузере.

```bash
pnpm install
pnpm dev
```

Документация для разработки — `CLAUDE.md` и каталог `docs/`.
