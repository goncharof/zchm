# Состояние проекта

Обновлено: 2026-10-17 (третья итерация).

## Что работает
- Полный конвейер данных из оцифрованной коробки (см. `docs/ARCHITECTURE.md`): бестиарий с рисунками, Книга Жизни по параграфам с подсказками, карта мира с дорогами, правила.
- Движок: персонажи 5 классов, уровни 0–12 (включая особенности 12 уровня), экипировка с ограничениями класса, бой по Инструкции (дистанция → инициатива → раунды, храбрость, доп. атаки, бегство, статусы), призванные существа и иллюзии как союзники, магия монстров, 91 заклинание (73 автоматизированы: урон, контроль, защитные ауры, магическое оружие, призывы, лечение, опознание, воскрешение; 18 — вручную по описанию), бутылки, свитки, артефакты, яд, отдых.
- Книга Жизни для игры без ведущего: 268 параграфов разбиты на сцену и ветки решений (исход раскрывается по выбору), списки исходов разыгрываются кнопкой броска, кнопки боя берут число врагов из текста.
- Игра проходима до конца: финальная дуэль с Чёрным магом в §13 замка отыгрывается сценарием, победа фиксируется на главной.
- Приложение: все экраны из `docs/ARCHITECTURE.md` плюс «Предыстория» (Книга Сумерек), автосохранение с миграцией старых сохранений, экспорт/импорт, режим ведущего (скрывает текст параграфов). В бою цель выбирается кликом по карточке, у кнопок атаки показан нужный бросок.
- Тесты: `pnpm test` — 34 теста: кубики, персонаж, инвентарь, бой, заклинания, маршруты, стор и сквозной прогон приложения в jsdom (`tests/app.test.ts` монтирует App, проходит все экраны, проводит бой и проверяет отсутствие ошибок и Vue-предупреждений). `pnpm typecheck` и `pnpm build` проходят.

## Проверка интерфейса
- `node tools/qa/screens.mjs` (при запущенном `pnpm dev`) проходит игру в Chrome на ширине 1280 и 390 px, снимает скриншоты всех экранов в `tools/qa/out/` и сообщает об ошибках консоли, HTTP-ошибках и горизонтальной прокрутке. Последний прогон — без замечаний.

## Известные упрощения и долги
- Боеприпасы (стрелы, дротики) не расходуются; эльфийская стрела как предмет не влияет на меткость (ХАУСРУЛ: считать, что стрел достаточно). Можно добавить учёт.
- Доп. атака монстра: если у монстра несколько видов, используется первая.
- Монстры колдуют только боевые заклинания (урон и контроль); лечение/бафы монстров не отыгрываются.
- `hints.coins` ловит и цены у торговцев — кнопка «+N монет» иногда лишняя.
- «Удвоение жидкости», «Двойник», «Воплощение», «Отражение магии» и другие нечисловые заклинания — вручную (список в `docs/DECISIONS.md`).
- Главный бандл 690 КБ: locations.json и bestiary.json входят в него целиком; при желании вынести в ленивую загрузку.
- Нет сетевого режима; одна партия на один браузер (несколько — через экспорт/импорт).
