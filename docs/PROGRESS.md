# Состояние проекта

Обновлено: 2026-10-17.

## Что работает
- Полный конвейер данных из оцифрованной коробки (см. `docs/ARCHITECTURE.md`): бестиарий с рисунками, Книга Жизни по параграфам с подсказками, карта мира с дорогами, правила.
- Движок: персонажи 5 классов, уровни 0–12, экипировка с ограничениями класса, бой по Инструкции (дистанция → инициатива → раунды, храбрость, доп. атаки, бегство, статусы), 91 заклинание (эффекты урона/лечения/бафов/бегства автоматизированы, остальные — вручную по описанию), бутылки, свитки, артефакты, яд, отдых.
- Приложение: все экраны из `docs/ARCHITECTURE.md`, автосохранение, экспорт/импорт, режим ведущего (скрывает текст параграфов).
- Тесты: `pnpm test` — 24 теста (кубики, персонаж, инвентарь, бой, заклинания, маршруты, стор). `pnpm typecheck` и `pnpm build` проходят.

## Не проверено
- Интерфейс не прогонялся в браузере глазами (нет средств автоматизации в сессии). Первое, что стоит сделать: `pnpm dev`, собрать партию, купить снаряжение, сходить в Золотой город, провести бой.

## Известные упрощения и долги
- Боеприпасы (стрелы, дротики) не расходуются; эльфийская стрела как предмет не влияет на меткость (ХАУСРУЛ: считать, что стрел достаточно). Можно добавить учёт.
- Заклинания монстров в бою не применяются автоматически (список показан; ведущий отыгрывает вручную).
- Доп. атака монстра: если у монстра несколько видов, используется первая.
- `hints.coins` ловит и цены у торговцев — кнопка «+N монет» иногда лишняя.
- Призванные существа (пантера, дракон, рука) не становятся участниками боя — только запись в журнале.
- Бутылки, созданные «Алхимией», и «Удвоение жидкости» — вручную.
- Главный бандл 690 КБ: locations.json и bestiary.json входят в него целиком; при желании вынести в ленивую загрузку.
- Нет сетевого режима; одна партия на один браузер (несколько — через экспорт/импорт).

## Следующие шаги (по приоритету)
1. Ручной прогон в браузере и починка найденного.
2. Удобства боя: выбор цели по клику на карточку, подсветка активного героя, звук/анимация броска (необязательно).
3. Ветвления параграфов: для 2–3 первых локаций разметить выборы явно (кнопки «Если помогаете…»), чтобы играть без ведущего совсем гладко. Формат: расширить `Paragraph` полем `choices` в `tools/build_book_of_life.py` или отдельным файлом правок `src/data/overrides/`.
4. Заклинания: автоматизировать «Паутину», «Паралич», «Окаменение», «Оледенение», «Засыпание» на монстров (сейчас через `disabled`/`petrified` в модели, но эффекты помечены как manual в данных).
5. Учёт боеприпасов и коня как предмета (сейчас конь учитывается при расчёте дней пути).
6. Деплой на GitHub Pages (`base: './'` уже настроен): `pnpm build` → каталог `dist/`.
7. Книга Сумерек как раздел «Предыстория» (текст есть в `source/text/Kniga_Sumerek.txt`, 37 стр.).
