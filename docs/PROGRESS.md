# Состояние проекта

Обновлено: 2026-10-17 (третья итерация).

## Что работает
- Полный конвейер данных из оцифрованной коробки (см. `docs/ARCHITECTURE.md`): бестиарий с рисунками, Книга Жизни по параграфам с подсказками, карта мира с дорогами, правила.
- Движок: персонажи 5 классов, уровни 0–12 (включая особенности 12 уровня), экипировка с ограничениями класса, бой по Инструкции (дистанция → инициатива → раунды, храбрость, доп. атаки, бегство, статусы), призванные существа и иллюзии как союзники, магия монстров, 91 заклинание (73 автоматизированы: урон, контроль, защитные ауры, магическое оружие, призывы, лечение, опознание, воскрешение; 18 — вручную по описанию), бутылки, свитки, артефакты, яд, отдых.
- Раздел «Правила» — справка для игроков (таблицы уровней, оружия, доспехов строятся из данных); полоса опыта у героя, счётчик пройденных параграфов в локации.
- Быстрый старт одной кнопкой; установка на телефон (манифест, иконки) и игра без сети (service worker, проверено `tools/qa/offline.mjs`).
- Спутники: существо из текста можно нанять на N боёв, оно сражается за партию; в параграфах с тавернами — отдых, с торговцами — переход в лавку.
- Боеприпасы: стрелы расходуются, дротики и копья бросаются и подбираются после победы. Многоголовые чудовища: огр 16 жизней, гидра девятью головами с отрастанием.
- Книга Жизни для игры без ведущего: 277 параграфов разбиты на сцену и 399 веток решений (исход раскрывается по выбору), списки исходов разыгрываются кнопкой броска, кнопки боя берут число врагов из текста.
- Игра проходима до конца: финальная дуэль с Чёрным магом в §13 замка отыгрывается сценарием, победа фиксируется на главной.
- Приложение: все экраны из `docs/ARCHITECTURE.md` плюс «Предыстория» (Книга Сумерек), автосохранение с миграцией старых сохранений, три слота сохранения в браузере, экспорт/импорт, маршрут и посещённые локации на карте, кнопки «Заплатить N монет» для цен из текста, режим ведущего (скрывает текст параграфов). В бою цель выбирается кликом по карточке, у кнопок атаки показан нужный бросок.
- Тесты: `pnpm test` — 44 теста, включая проверку целостности сгенерированных данных (`tests/data.test.ts`): кубики, персонаж, инвентарь, бой, заклинания, маршруты, стор и сквозной прогон приложения в jsdom (`tests/app.test.ts` монтирует App, проходит все экраны, проводит бой и проверяет отсутствие ошибок и Vue-предупреждений). `pnpm typecheck` и `pnpm build` проходят.

## Проверка интерфейса
- `node tools/qa/screens.mjs` (при запущенном `pnpm dev`) проходит игру в Chrome на ширине 1280 и 390 px, снимает скриншоты всех экранов в `tools/qa/out/` и сообщает об ошибках консоли, HTTP-ошибках и горизонтальной прокрутке. Последний прогон — без замечаний.

## Известные упрощения и долги
- Доп. атака монстра: если у монстра несколько видов, используется первая.
- Монстры колдуют только боевые заклинания (урон и контроль); лечение/бафы монстров не отыгрываются.
- «Удвоение жидкости», «Двойник», «Воплощение», «Отражение магии» и другие нечисловые заклинания — вручную (список в `docs/DECISIONS.md`).
- Сборка: код 71 КБ, библиотеки 97 КБ, данные игры отдельным чанком 808 КБ (160 КБ gzip), Книга Сумерек грузится лениво. Ещё меньше можно сделать, если хранить у параграфов с сегментами только сегменты без дубля текста.
- Нет сетевого режима; одна партия на один браузер (несколько — через экспорт/импорт).
